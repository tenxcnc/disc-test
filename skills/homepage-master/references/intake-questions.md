# 기본 질문

자료를 먼저 본 뒤, 답을 찾지 못한 것만 묻는다. 한 번에 3~5개를 번호로 묶어 묻고, 각 질문에 "모르시면 이렇게 하겠습니다"라는 기본값을 붙인다. 그래야 답이 없어도 진행할 수 있다.

## 꼭 필요한 질문 (사실)

| 묻는 것 | 왜 필요한가 | 답이 없을 때 기본값 |
|---|---|---|
| 무엇을 누구에게 파는가 | 첫 화면 문장과 섹션 순서가 정해진다 | 기존 자료에서 추정하고 가정으로 표시 |
| 방문자가 할 행동 하나 | 버튼과 폼이 정해진다 | 문의 폼 + 전화 |
| 가장 밀고 싶은 서비스 | 강조 카드와 첫 화면이 정해진다 | 최근 실적이 많은 것 |
| 방문자가 망설이는 이유 | 근거를 어디에 둘지 정해진다 | 업종의 흔한 걱정(가격, 신뢰, 결과) |
| 실적·자격·고객사와 출처 | 지어낼 수 없는 내용이다 | 자료에 있는 것만 쓰고 나머지는 뺀다 |
| 로고 원본, 사진, 기존 문구 | 자산이 디자인을 정한다 | 글자 중심으로 구성하고 사진 자리는 두지 않는다 |
| 손대면 안 되는 것 | 로고 색, 표어, 기존 주소 등 | 브랜드 자산 전부를 건드리지 않는다 |
| 문의가 접수되는 곳 | 폼이 실제로 동작해야 한다 | 메일 링크와 전화만 두고 폼은 보류 |
| 도메인, 배포 위치, 언어 | 주소·메타 정보가 정해진다 | 정적 파일로 만들고 배포는 안내만 |

## 있으면 좋은 질문 (방향)

- 경쟁사가 따라 말할 수 없는 우리만의 사실은 무엇인가
- 좋아하는 사이트와 싫어하는 사이트, 그리고 이유
- 완성도가 높아도 "우리 같지 않다"고 느낄 모습은 무엇인가
- 밝은 버전과 어두운 버전 중 필요한 것, 두 가지 모두 필요한가
- 사진 속 인물의 게재 동의가 있는가

## 묻지 않는 것

- 색상 코드, 글꼴 이름 같은 세부 취향. 시안으로 보여 주고 고르게 한다.
- 자료에 이미 적힌 것.
- 답이 달라져도 결과가 같은 것.

## 자료끼리 다를 때

같은 정보가 자료마다 다르면(주소, 연도, 직함, 수치) 최신 날짜의 공식 문서를 따르고, 다른 값이 있었다는 것을 보고의 "확인해 주실 것"에 적는다. 임의로 하나를 골라 조용히 넘어가지 않는다.
