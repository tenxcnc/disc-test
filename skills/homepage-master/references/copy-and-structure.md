# 문구와 구성

## 섹션 순서의 기본 틀

회사·서비스 홈페이지의 기본 순서다. 자료가 없는 섹션은 뺀다.

1. 첫 화면: 무엇을, 누구에게, 무엇이 달라지는지, 버튼
2. 신뢰 띠: 고객사 이름이나 핵심 수치
3. 하는 일: 서비스 목록. 많으면 분류해서 고르게 한다
4. 대표 서비스 강조: 가장 밀고 싶은 것 하나를 크게
5. 일하는 방식: 3~5단계
6. 실적: 연도, 고객, 한 일
7. 제작·수행 사례
8. 사람: 대표, 자격, 팀
9. 자료: 브로셔, 소개서
10. 문의: 갈래가 다르면 문의 경로를 나눈다

문의 종류가 뚜렷이 다르면(예: AI 교육 문의와 기업교육 문의) 전용 문의 페이지를 따로 두고, 메인에서는 갈림길 카드로 보낸다.

## 첫 화면

- 제목에 업종이나 대상이 들어가야 한다. "성장을 디자인합니다" 같은 문장은 어느 회사에나 붙는다.
- 사실 하나를 넣는다. 연수, 인원, 자격처럼 확인된 것만.
- 버튼은 주 버튼 하나, 보조 하나까지.

## 문장 규칙

- 버튼: "동사 + 얻는 것". 같은 행동은 사이트 전체에서 같은 말로.
- 서비스 설명: 무엇을 하는지 → 누구에게 → 결과물. 두세 문장.
- 근거 줄: "수행", "자격", "도구"처럼 종류를 붙여 설명 아래에 둔다.
- 문장마다 묻는다. 사실인가, 이 회사만의 이야기인가, 방문자가 다음 행동을 정하는 데 도움이 되는가. 셋 다 아니면 지운다.
- 번역 투, 과장어("혁신적인", "최고의"), 뜻 없는 영어 소제목을 피한다.

## 근거와 정직

- 수치, 후기, 고객사, 수상, 자격은 출처가 있는 것만 쓴다.
- 자격은 상태를 구분한다. 보유, 심사 중, 수료는 서로 다르다. 유효기간은 증빙이 있을 때만 적는다.
- 자격 설명은 발급 기관 안내를 기준으로 쓰고, 원문을 확인하지 못했으면 수치를 빼고 보고에 적는다.
- 사용자가 준 수치라도 자료와 다르면 그대로 두고 확인을 요청한다.
- 예시 후기는 공개 화면에 올리지 않는다. 실제 후기가 올 때까지 섹션을 뺀다.
- 고객사·참여 업체 이름을 싣기 전에 게재를 알렸는지 확인을 요청한다.
