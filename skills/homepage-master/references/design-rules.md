# 디자인 기준

## 순서

1. 코드 전에 방향을 여섯 줄로 적는다: 대상, 분위기 한 단어, 바탕과 글자색, 강조색 하나, 글꼴, 이 사이트만의 한 가지.
2. 그 계획이 요청과 맞는지 다시 읽는다.
3. 그다음 만든다.

**사용자의 지시가 항상 이긴다.** 아래 금지 목록은 사용자가 정하지 않은 부분에만 적용한다. 사용자가 검정 바탕에 네온 강조를 원하면 그대로 만든다.

## 피할 것 (기본값으로 고르지 말 것)

누구나 AI가 만들었다고 알아보는 모습이다.

- 보라·파랑 그라데이션 배경, 번지는 광채, 유리 느낌 카드 남발
- 모든 것을 가운데 정렬
- 크기와 모양이 똑같은 카드만 반복
- 아이콘 대신 이모지
- 섹션마다 똑같이 떠오르는 스크롤 효과
- 뜻 없는 영어 대문자 머리말, 장식용 01/02/03 번호
- 크림색 바탕 + 세리프 + 붉은 흙색 조합처럼 유행하는 묶음을 그대로 쓰는 것

번호와 머리말은 실제 순서나 분류를 나타낼 때만 쓴다.

## 지킬 것

- **색**: 바탕, 면, 선, 글자 3단계, 강조색 하나. 강조색은 버튼·링크·핵심 글자에만 쓴다. 변수로 정의해 버전 전환이 쉽게 한다.
- **글자**: 제목과 본문의 크기 차이를 크게. 본문 16~17px, 줄 간격 1.6~1.7. 제목은 화면 폭에 따라 줄어들게.
- **구성**: 한 화면에 가장 중요한 것 하나. 강조할 카드는 크기로 구분한다.
- **여백**: 섹션 사이는 넉넉하게, 관련 있는 것끼리는 가깝게.
- **움직임**: 의미 있는 곳 한두 군데만. 움직임 줄이기 설정을 따른다.
- **사진**: 실제 사진이 일반 이미지보다 낫다. 사진이 없으면 글자와 선으로 완성도를 낸다.

## 밝은 버전과 어두운 버전

- 내용은 하나로 관리하고 색 변수만 바꾼다. 내용을 고칠 때 두 버전에 함께 반영한다.
- 한쪽에서 잘 보이던 강조색이 다른 쪽에서 읽히지 않을 수 있다. 버전마다 대비를 확인하고 필요하면 강조색을 따로 정한다.
- 로고는 버전에 맞는 **원본 파일**을 쓴다. 한 파일의 색을 뒤집어 쓰지 않는다.

## 브랜드 자산

- 로고를 다시 그리거나, 색을 바꾸거나, 사이트 강조색에 맞추지 않는다.
- 허용되는 처리는 배경 제거, 자르기, 크기 조절이다. 처리 뒤 본체 색이 원본과 같은지 확인한다.
- 벡터 원본이 없으면 있는 파일로 쓰고, 원본을 요청한다고 보고에 적는다.

## 사진과 초상권

- 얼굴이 식별되는 사진은 게재 동의를 확인한다. 동의가 없으면 얼굴 없는 구도를 고르거나 얼굴을 가린다.
- 명찰, 화면 속 이름, 내부 자료가 보이는 화면도 가린다.
- 실적과 현장을 보여 주는 자리에 AI로 만든 사람 이미지를 쓰지 않는다. 하지 않은 일을 한 것처럼 보이게 된다.
- 사진 설명에는 실제 장면을 적는다.

## 첫 화면에 사진·영상을 넣을 때

- 슬라이드는 가볍고 교체가 쉽다. 5초 안팎 간격, 일시정지 가능, 움직임 줄이기 설정 대응.
- 영상은 소스가 있고 용량을 감당할 수 있을 때만. 자동 재생 영상은 휴대폰 첫 화면을 느리게 한다.
- 전체 배경으로 깔면 글자가 읽히도록 어두운 막이 필요하다. 사용자가 정한 색 기준과 부딪히면 시안으로 보여 주고 고르게 한다.
